## Selected work

### `01` Conduit · full-stack RealWorld platform

[Open repository →](https://github.com/aziz7042/conduit-realworld-platform)

**University team project** — an end-to-end publishing platform with an ASP.NET Core API, Vue 3 web client, Flutter mobile client and SQLite persistence.

`C#` · `.NET` · `Vue 3` · `TypeScript` · `Flutter` · `Dart` · `REST` · `Swagger` · `EF Core`

- Authentication, profiles, articles, comments, favorites and personalized feeds
- Web and mobile Markdown editing, preview and image-upload workflows
- API documentation, migrations, test data, automated tests and architecture diagrams

---

### `02` BARN World 037 · ROS 2 localization & navigation

[Open repository →](https://github.com/aziz7042/barn-ros2-navigation)

**University team project** — autonomous navigation for a four-wheel skid-steer robot in a difficult simulated environment.

`ROS 2 Jazzy` · `Python` · `Nav2` · `Gazebo` · `RViz` · `EKF` · `LiDAR` · `IMU` · `ArUco`

- Local state estimation from wheel odometry and IMU
- Global correction using visual markers and gradual `map → odom` alignment
- Planning, path following, collision avoidance and custom recovery actions

---

### `03` King's Last Castle · 3D tower-defense game

[Open repository →](https://github.com/aziz7042/kings-last-castle)

**University team project · team lead** — a complete MonoGame experience with three maps, multiple waves and difficulties, three tower types, three enemy types, path switching and a Royal Power ability.

`C#` · `.NET 9` · `MonoGame` · `OOP` · `Game State Management`

My focus included gameplay flow, game states, menus, HUD, waves, gold, castle health, Royal Power and final integration. The current source builds successfully with **zero warnings and zero errors**.
